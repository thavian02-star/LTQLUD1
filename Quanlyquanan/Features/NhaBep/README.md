# PHÂN HỆ: NHÀ BẾP & PHA CHẾ (NHA BEP)

Chứa toàn bộ các thành phần phục vụ nhân viên bếp và quầy bar:
- `frmNhaBep.vb` (Hàng đợi món cần chế biến theo thứ tự thời gian gọi món)
- `NhaBepDAO.vb` (Truy vấn món ăn trạng thái 0: Chờ nấu, cập nhật sang 1: Đang nấu, 2: Đã nấu xong)
- `NhaBepBUS.vb` (Xử lý thông báo món hoàn thành cho nhân viên phục vụ)

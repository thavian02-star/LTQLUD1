# PHÂN HỆ: XÁC THỰC & TÀI KHOẢN (AUTH)

Chứa toàn bộ các thành phần phục vụ việc đăng nhập, quản lý phiên và đổi mật khẩu:
- `frmDangNhap.vb` (Giao diện đăng nhập hệ thống)
- `frmDoiMatKhau.vb` (Giao diện đổi mật khẩu cá nhân)
- `TaiKhoanDTO.vb` (Thực thể tài khoản người dùng)
- `TaiKhoanDAO.vb` (Truy vấn bảng TaiKhoan, TaiKhoan_VaiTro, VaiTro_Quyen)
- `AuthBUS.vb` (Xác thực thông tin, nạp Session, kiểm tra phân quyền)

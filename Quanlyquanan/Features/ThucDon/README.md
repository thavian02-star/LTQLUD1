# PHÂN HỆ: THỰC ĐƠN & DANH MỤC MÓN (THUC DON)

Chứa toàn bộ các thành phần quản trị món ăn và danh mục:
- `frmThucDon.vb` (Quản lý danh sách món ăn, giá bán, trạng thái hết món)
- `MonAnDTO.vb`, `DanhMucDTO.vb` (Thực thể món ăn và danh mục)
- `MonAnDAO.vb`, `DanhMucDAO.vb` (Truy vấn bảng MonAn, DanhMuc)
- `ThucDonBUS.vb` (Kiểm tra hợp lệ giá bán, cảnh báo món hết hàng)

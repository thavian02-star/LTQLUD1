HƯỚNG DẪN KHỞI CHẠY, SEED DATA, KIỂM THỬ & ĐÓNG GÓI

Tài liệu từng bước hướng dẫn khởi động cơ sở dữ liệu Docker, cơ chế nạp dữ liệu mẫu (Seed Data), danh sách tài khoản test và mật khẩu, ma trận phân quyền chi tiết cho từng vai trò và quy chuẩn dọn dẹp đóng gói gửi source sang máy khác chạy được ngay.

🐳 1. Khởi Chạy Docker & Cơ Chế Seed Data Mẫu

1 Cách Khởi Động Docker Container SQL Server 2022 (1-Click)

Hệ thống cơ sở dữ liệu đã được cấu hình trọn gói chạy bằng Docker container để không phụ thuộc vào việc máy tính người dùng có cài đặt SQL Server cục bộ hay không.

🖥️ Trên Hệ Điều Hành Windows

1. Mở phần mềm Docker Desktop (đảm bảo trạng thái Engine Running xanh lá).
2. Nhấp đúp chuột trực tiếp vào file kịch bản:

database\docker-mssql\start-db.bat

Script sẽ tự động gọi docker-compose up -d --build và nạp dữ liệu.

🍎 Trên macOS hoặc Linux

Mở Terminal tại thư mục gốc dự án và chạy lệnh:

cd database/docker-mssql docker compose up -d --build

Container sql-server-quanlyquanan sẽ chạy ngầm tại cổng 1433.

2 Cơ Chế Tự Động Nạp Dữ Liệu Mẫu (Auto Seed Data)

Cơ chế tự động 100%: File script database/docker-mssql/run-initialization.sh được container tự động kích hoạt ngay khi khởi động. Script sẽ lắng nghe trạng thái của SQL Server: ngay khi cổng 1433 sẵn sàng nhận kết nối, hệ thống sẽ thực thi tự động:
  1. File create-database.sql: Tạo Database QuanLyQuanAnDB và 19 bảng kèm ràng buộc toàn vẹn.
  2. File seed-data.sql: Tự động nạp sẵn tài khoản, vai trò, quyền, nhân viên, 2 ca làm việc, khu vực bàn ăn và thực đơn món ăn.

3 Cách Nạp Lại Dữ Liệu Thủ Công (Reset / Re-seed Data)

Nếu trong quá trình test bạn muốn nạp lại dữ liệu mẫu hoặc kiểm tra trực tiếp qua dòng lệnh:

# Lệnh thực thi nạp lại seed-data.sql trực tiếp vào Docker Container: docker exec -i sql-server-quanlyquanan /opt/mssql-tools18/bin/sqlcmd \ -S localhost -U sa -P 'password123!' -C \ -d QuanLyQuanAnDB -i /usr/src/app/seed-data.sql
💡 Hoặc qua công cụ trực quan: Mở DBeaver, Azure Data Studio hoặc SSMS ➔ Kết nối localhost,1433 (User: sa, Pass: password123!) ➔ Mở file database/docker-mssql/seed-data.sql và nhấn F5 để chạy.

📋 4. Kịch Bản Kiểm Thử Mẫu (Test Walkthrough)

  1. Mở ứng dụng ➔ Đăng nhập tài khoản phucvu1 / mật khẩu 123456.
  2. Quan sát Menu/Thanh chức năng: Nút Báo Cáo Doanh Thu, Quản Lý Nhân Sự, Phân Quyền tự động bị ẩn hoặc mờ xám (Disabled).
  3. Đăng xuất ➔ Đăng nhập tài khoản chuquan / 123456: Toàn bộ nút chức năng sáng lên và thao tác bình thường.
🧪 Kịch Bản 2: Luồng Nghiệp Vụ Gọi Món ➔ Bếp ➔ Thanh Toán End-to-End Workflow
Mục tiêu: Kiểm tra tính nhất quán dữ liệu giữa Phục vụ, Nhà bếp và Thu ngân.
  1. Phục vụ (phucvu1): Mở màn hình Sơ đồ bàn ➔ Chọn bàn trống số 01 (Bàn đổi sang màu xanh/đỏ báo có khách) ➔ Chọn món "Phở Bò Đặc Biệt", thêm ghi chú "Ít hành" ➔ Bấm Lưu & Chuyển Bếp.
  2. Nhà bếp (nhabep1): Mở màn hình Nhà Bếp ➔ Thấy ngay dòng order của Bàn 01 xuất hiện đầu tiên (thứ tự FIFO) kèm ghi chú "Ít hành" ➔ Bấm Nấu xong (Món chuyển sang trạng thái đã chế biến).
  3. Thu ngân (quanly hoặc phucvu1): Bấm chọn Bàn 01 ➔ Bấm In Hóa Đơn Tạm Tính ➔ Chọn phương thức thanh toán "Tiền mặt" ➔ Bấm Thanh Toán ➔ Hóa đơn đóng lại, bàn 01 tự động trở về trạng thái Trống.
🧪 Kịch Bản 3: Luồng Chấm Công Cá Nhân ➔ Quản Lý Duyệt Công HR & Attendance Flow
Mục tiêu: Xác thực quy trình tính công minh bạch của quán.
  1. Nhân viên (phucvu1): Vào màn hình Chấm công cá nhân ➔ Bấm Vào Ca (Hệ thống ghi nhận thời điểm thực tế vào bảng ChamCong với trạng thái CC_DaDuyet = 0).
  2. Sau ca làm việc: Bấm Ra Ca.
  3. Quản lý (quanly): Vào màn hình Duyệt chấm công ➔ Xem danh sách nhân viên làm việc hôm nay ➔ Bấm nút Duyệt Công (Hệ thống cập nhật cờ CC_DaDuyet = 1 và lưu mã CC_NguoiDuyet).

📦 5. Hướng Dẫn Đóng Gói Gửi Source Cho Máy Khác Test

1 Quy Chuẩn Dọn Dẹp File Rác Trước Khi Nén Zip

Trước khi gửi source code cho người khác hoặc nộp bài, bắt buộc phải xóa sạch các thư mục sinh tự động khi build để tránh xung đột mã máy, giảm dung lượng file nén từ 200MB+ xuống còn chỉ khoảng 5MB - 10MB:

Thư Mục / File Trạng Thái Lý Do Kỹ Thuật
Quanlyquanan/bin/ Bắt buộc XÓA Chứa các file .dll, .exe đã build cục bộ trên máy bạn. Máy người nhận sẽ tự compile lại khi nhấn F5.
Quanlyquanan/obj/ Bắt buộc XÓA Chứa file cache tạm của compiler, rất nặng và dễ gây lỗi cache cũ (Missing assembly).
.vs/ Bắt buộc XÓA Thư mục ẩn của Visual Studio lưu vị trí con trỏ chuột, layout cửa sổ riêng của máy bạn.
.DS_Store Bắt buộc XÓA File rác do hệ điều hành macOS tự sinh ra.
Quanlyquanan/ (Code .vb) Bắt buộc GIỮ Toàn bộ mã nguồn, Form, Core, Features, file .vbproj và .slnx.
database/ Bắt buộc GIỮ Chứa docker-mssql (Dockerfile, docker-compose.yml, script khởi tạo và seed data).
docs/ & README.md Bắt buộc GIỮ Tài liệu hướng dẫn và các trang HTML hỗ trợ giáo viên/người chấm bài xem tổng quan.

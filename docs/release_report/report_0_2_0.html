Đấu Nối Chuyển Hướng & Quản Lý Vòng Đời Đăng Xuất An Toàn

Commit: 5fad458 · File: frmDangNhap.vb, frmMain.vb

Giải quyết triệt để vấn đề xung đột vòng đời Form trong WinForms (.NET 10.0). Khi đăng nhập thành công, Form đăng nhập chỉ ẩn đi (Me.Hide()) chứ không đóng để giữ tiến trình ứng dụng. Khi người dùng bấm ĐĂNG XUẤT trên màn hình chính, hệ thống gửi tín hiệu DialogResult.OK để mở lại Form Đăng nhập, đồng thời xóa sạch Session. Khi người dùng bấm [X], hệ thống hỏi xác nhận và thoát hoàn toàn ứng dụng.

frmDangNhap.vb — Luồng chuyển giao diện an toàn VB.NET
+ ' Khởi tạo frmMain và ẩn frmDangNhap
+ Dim fMain As New Features.Main.frmMain()
+ AddHandler fMain.FormClosed, Sub(s, args)
+ If fMain.DialogResult = DialogResult.OK Then
+ ' Người dùng bấm Đăng Xuất -> Hiện lại form Đăng nhập sạch sẽ
+ Me.Show()
+ txtTenDangNhap.Focus()
+ Else
+ ' Người dùng bấm [X] thoát -> Kết thúc hoàn toàn app
+ Me.Close()
+ End If
+ End Sub
+ fMain.Show()
+ Me.Hide()
